# RISC-V
A RISC-V program that computes for the average of a list of integers.

The program first ask the user to input n, which is the number of elements in the list, via an input dialog box. Then, make the user input the elements of the list, one at a time, via the console/command line. Get the sum of the elements and store it in memory variable SUM. Lastly, compute the average (floating point), then print it to the user via a message dialog box.
